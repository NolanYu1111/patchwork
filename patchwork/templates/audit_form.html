Skin-tone contrast

Per-band counts are usually too small to interpret, so the main result is a two-group contrast (I–IV vs V–VI, following Groh et al.).

Expected format

case_id,label,score,fitzpatrick
A001,1,0.82,II
A002,0,0.14,V
A003,0,0.37,6

label is 1 for the positive class (for example psoriasis) and 0 otherwise.
