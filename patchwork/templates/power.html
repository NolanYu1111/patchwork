How this is calculated

Standard error of each group's AUROC from Hanley & McNeil (1982), which depends on the AUROC and the number of positive and negative cases. The groups contain different people, so the gap's standard error is the root sum of squares. Power is the probability that a 95% interval for the gap excludes zero if the gap is real. This is an approximation for planning; the audit itself uses the bootstrap.
